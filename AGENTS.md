# MechLab VR

- Рабочий код проекта находится в `Assets/_Project`. Перед правкой сценария или сцены сверяйся с `DEMO_PROGRESS.md`. Общая архитектура описана в `AI_CONTEXT.md`, а точная версия редактора указана в `ProjectSettings/ProjectVersion.txt`.
- При работе с кодом применяй Ponytail. Используй ясные имена, сохраняй ответственность классов и направление зависимостей, переиспользуй существующие механизмы. Добавляй абстракцию, только если она упрощает текущую задачу.
- Перед реализацией покажи предлагаемый diff и список файлов. Проверяй изменённое поведение через штатную точку входа. Отдельно указывай результаты компиляции, прогона в редакторе и проверки в шлеме.
- Используй Superpowers для отладки и проверки изменений. При ревью начинай с Code Review Graph для поиска зависимостей и подтверждай выводы по исходникам и фактическому diff.
